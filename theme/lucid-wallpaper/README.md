# Lucid Wallpapers
Standalone Android wallpaper picker prototype for the Lucid OS UI branch.
- Four generated wallpaper styles, including the requested bubbles aesthetic.
- Live preview and applies selected artwork through Android WallpaperManager.
- Java-only Android SDK build workflow publishes a short-lived APK artifact.
- This is not yet wired into the ROM's system wallpaper picker or runtime theme engine.
