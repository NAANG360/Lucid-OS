# Lucid Launcher

Lucid's home activity is a real HOME surface: Lucid identity header, clock/glance card, quick links, searchable launchable-app grid and no permanent bottom dock. The system navigation bar remains Android-owned. Long-press an app for Open, App info, Uninstall and Share; long-press the home surface for launcher actions. Customizations persist across launches: 3–6 columns, 40–64 dp icons, labels and the glance card. The settings shortcut launches `com.lucid.os.settings` explicitly and never falls back to Android Settings.

The launcher deliberately does not claim widget hosting, drag-and-drop workspace placement, folders or gesture customization until those features are implemented and tested.
