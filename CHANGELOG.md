# Changelog

Changes worth knowing about, written in plain English. The GitHub release page remains the source for the files attached to each build.

## Build 3 — Android 15 / lavender

Build 3 is the current published ROM package.

- Updated the Lucid setup flow and its privileged permissions.
- Refreshed the Lucid wallpapers, About screen, and boot animation.
- Added System Updater integration.
- Published the ROM ZIP and updater-related downloads in the release assets.

**What this does not confirm:** a successful flash or first boot on a physical Redmi Note 7/7S. Treat the package as a development build, back up your data, and read the current release page before installing.

## System Updater v0.4.4-dev

- Published a refreshed recovery installer ZIP for the updater app.
- The recovery installer is separate from the ROM ZIP.
- Download and checksum files are attached to the Build 3 release.

The installer package being published does not by itself prove compatibility with every recovery. If it fails, keep the recovery log so the issue can be reproduced.
